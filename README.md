## Sobre

Primeiros scripts Python escritos com IA como copiloto.
A ideia e simples: eu descrevo o que quero, a IA sugere o codigo, eu entendo, adapto e executo.

## Como rodar

**Pre-requisito:** Python 3.x instalado

```bash
git clone https://github.com/NaiaraRodrigues-naih/PYTHON-DO-ZERO-COM-COPILOTO-IA.git
cd PYTHON-DO-ZERO-COM-COPILOTO-IA/semana-02
python ola.py
```

Cada arquivo e independente — execute qualquer um diretamente.
